Parakeet on ggml WebGPU

Live microphone transcription with the same runtime

transcribe.cpp + ggml WebGPU backend compiled to WASM; quantized weights stay packed on the GPU. Models: NVIDIA parakeet-tdt_ctc-110m (default) and parakeet-tdt-0.6b-v2. The model file is fetched from this server and kept in this browser (OPFS). Tap a configuration to load it and run; every finished step is saved, so if the tab dies, reload and look under "Earlier runs".
